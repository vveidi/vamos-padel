# 11: Список матчей на iPhone

**What to build:** На телефоне появляется история. Открыв приложение, владелец видит список сыгранных матчей: дата, счёт, длительность и то, по какому **набору правил** игрался матч — иначе счёт «16:14» выглядит странным теннисным результатом.

**Недоигранные матчи** отличаются с одного взгляда, без вчитывания.

Приложение только для iPhone; iPad из таргета убран.

**Blocked by:** 10, 09

**Status:** ready-for-agent

- [ ] Список показывает матчи, начиная с самых свежих
- [ ] Для каждого матча видны дата, итоговый счёт и длительность
- [ ] Видно, по какому набору правил игрался матч
- [ ] Недоигранные матчи отличаются визуально
- [ ] История переживает перезапуск приложения
- [ ] Пустая история выглядит осмысленно, а не как ошибка
