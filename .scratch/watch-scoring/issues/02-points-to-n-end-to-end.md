# 02: Счёт до N очков от начала до конца

**What to build:** Первый работающий счётчик. Игрок открывает приложение на часах и видит экран, поделённый на две равные половины. Касание половины отдаёт очко этой стороне, счёт на экране растёт. Как только сторона первой набирает N очков, матч заканчивается и показывается итог.

Самый простой **набор правил** — ни геймов, ни сетов, ни «ровно», ни подачи. После этого тикета приложением уже можно вести реальную игру.

Геометрия зон: две равные половины. Уточнение геометрии отложено до прототипа и этот тикет не блокирует.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Касание половины экрана добавляет розыгрыш в **журнал** и увеличивает счёт этой **стороны**
- [ ] Текущие очки показаны крупно и читаются мельком
- [ ] Матч заканчивается, как только сторона набирает N очков; дальнейшие касания счёт не меняют
- [ ] После окончания показывается итог матча
- [ ] N задаётся при создании матча, значение по умолчанию 16
- [ ] Состояние матча вычисляется из журнала и набора правил, а не хранится рядом с ним
- [ ] Один и тот же журнал, прочитанный дважды, даёт одно и то же состояние
- [ ] Тесты движка покрывают счёт до N, окончание матча и граничное значение N = 1
