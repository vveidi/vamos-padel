# 01: Каркас — watchOS-таргет и пакет PadelScoring

**What to build:** Приложение для Apple Watch, которое устанавливается и запускается, и локальный Swift-пакет `PadelScoring` с движком правил, на который приложение ссылается. Пользовательского поведения тикет не добавляет — это префактор, который делает возможными все остальные.

Пакет содержит доменные типы из глоссария: **набор правил**, **розыгрыш**, **журнал розыгрышей**, **состояние матча**. Логики счёта в нём пока нет, только формы, на которые ляжет тикет 02.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Приложение для часов собирается и запускается на симуляторе watchOS
- [x] Пакет `PadelScoring` подключён к таргету часов и к таргету iPhone
- [x] В пакете есть хотя бы один проходящий тест, который гоняется без симулятора
- [x] Пакет не импортирует ничего сверх явно разрешённого: GRDB и недоступные на macOS фреймворки ловит компилятор, SwiftUI и SwiftData — тест-предохранитель на белом списке
- [x] Таргет iPhone продолжает собираться

  `padel Watch App.app`; приложение установлено и запущено на Apple Watch Series 11

- **Ничего лишнего не импортируется**: белый список пуст, проверен на живом нарушении —
  `import Foundation` в исходнике роняет предохранитель.
- **iPhone продолжает собираться**: сборка схемы `padel` прошла; часы встроены
  в `padel.app/Watch/`.

Минимальные версии понижены до iOS 18 / watchOS 11 по ходу работы (см. раздел

### По итогам /code-review

Ревью прошло по двум осям и нашло восемь замечаний по спеке и одно жёсткое
нарушение стандартов. Что исправлено:

- **`Rally` против глоссария.** `CONTEXT.md` запрещал слово `rally` для термина
  «Розыгрыш», а типы названы `Rally`/`RallyJournal`. Решено, что ошибка в
  глоссарии: `rally` — законный английский идентификатор, как `Side` для стороны.
  Запрет снят с `rally`, на «очко» остался.
- **`MatchState` удалён.** Обоснование «не пишем счёт, чтобы не предрешать тикет 02»
  применялось ровно к одному полю: `servingSide` (тикет 04) и победитель (02/03)
  при этом отгружались. Структура нигде не конструировалась и ничем не покрывалась.
  Состояние матча целиком определит тикет 02.
- **`Completion` → `MatchOutcome`**, термин «Исход матча» внесён в глоссарий.
  Прежнее имя читалось как completion handler.
- **`Codable` снят со всех доменных типов.** Формат сериализации — решение
  тикета 07, и фиксировать его здесь значило предрешать миграции.
- **Предохранитель усилен.** Проверки импортов недостаточно: зависимость можно
  объявить в манифесте и не импортировать. Добавлена структурная проверка, что
  пакет не объявляет внешних зависимостей.
- **Схемы закоммичены** в `xcshareddata/`. Раньше они автосоздавались и лежали
  в `xcuserdata/`, который в `.gitignore`, — то есть сборка была воспроизводима
  только на машине автора.
- **Спека:** тай-брейк перестал числиться параметром набора правил, это правило
  падела.

Принято как есть: `removeLast()` и значения по умолчанию 16/4/1 формально
принадлежат тикетам 05, 02 и 04. Журнал без отмены — неполный тип, а константы
дешевле держать рядом с набором правил, чем расставлять по местам вызова.
