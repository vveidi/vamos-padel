# 05: Отмена последнего очка

**What to build:** Игрок может отменить ошибочно засчитанное очко. Промахи неизбежны: зоны большие, рука мокрая, а жест Double Tap срабатывает от постороннего движения. Без отмены единственным выходом остаётся бросить матч.

Отмена убирает последний **розыгрыш** из **журнала**; счёт, геймы, сеты и **подающая сторона** возвращаются ровно в то состояние, в котором были. Отменять можно несколько розыгрышей подряд.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] Есть жест отмены последнего очка на экране счёта
- [ ] После отмены состояние совпадает с состоянием до отменённого розыгрыша, включая подачу
- [ ] Отмена работает через границу гейма, сета и тай-брейка
- [ ] Отмена после окончания матча возвращает матч в незавершённое состояние
- [ ] Несколько отмен подряд откатывают журнал последовательно
- [ ] Отмена на пустом журнале ничего не ломает
- [ ] Тесты покрывают отмену через границу гейма и сета и отмену завершения матча
