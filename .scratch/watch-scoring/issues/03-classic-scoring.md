# 03: Классический счёт

**What to build:** Второй **набор правил** — падел по классическим правилам. Игрок выбирает его, и приложение считает 15/30/40, определяет конец гейма, сета и матча, при 6:6 начинает тай-брейк. Если включено **золотое очко**, счёт «ровно» разыгрывается одним решающим розыгрышем вместо игры до разницы в два.

На экране счёта рядом с очками появляется счёт по геймам — мельче, чем очки.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Очки идут 15 / 30 / 40 и гейм выигрывается при разнице в два
- [ ] При выключенном золотом очке счёт «ровно» продолжается до разницы в два
- [ ] При включённом золотом очке «ровно» разыгрывается одним розыгрышем
- [ ] Сет выигрывается при шести геймах и разнице в два
- [ ] При 6:6 начинается тай-брейк и разыгрывается по правилам падела
- [ ] Матч заканчивается при заданном числе выигранных сетов, по умолчанию одном
- [ ] Счёт по геймам показан на экране и не мешает читать очки
- [ ] Тесты покрывают: гейм, «ровно» в обоих режимах, конец сета, тай-брейк, конец матча
