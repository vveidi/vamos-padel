# 01: Каркас — watchOS-таргет и пакет PadelScoring

**What to build:** Приложение для Apple Watch, которое устанавливается и запускается, и локальный Swift-пакет `PadelScoring` с движком правил, на который приложение ссылается. Пользовательского поведения тикет не добавляет — это префактор, который делает возможными все остальные.

Пакет содержит доменные типы из глоссария: **набор правил**, **розыгрыш**, **журнал розыгрышей**, **состояние матча**. Логики счёта в нём пока нет, только формы, на которые ляжет тикет 02.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Приложение для часов собирается и запускается на симуляторе watchOS
- [ ] Пакет `PadelScoring` подключён к таргету часов и к таргету iPhone
- [ ] В пакете есть хотя бы один проходящий тест, который гоняется без симулятора
- [ ] Пакет не линкуется с SwiftUI, GRDB, HealthKit и WatchConnectivity — попытка их импортировать не компилируется
- [ ] Таргет iPhone продолжает собираться
